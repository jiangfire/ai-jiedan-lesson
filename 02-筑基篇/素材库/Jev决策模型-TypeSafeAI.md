## 一、它是什么（一句话版）

- TypeSafe AI 实验室 2026-09-15 发布的第一个 **"System One Model"（系统一模型）**，名叫 **Jev**。名字借自卡尼曼《思考，快与慢》：System 1 是快而直觉的判断，System 2 是慢而审慎的推理——Jev 只做前者。
- **不生成任何文字**（媒体叫它"闭嘴模型"）：给它一个状态（情境/材料）+ 一组问题，它直接返回**类型化判定 + 把握概率**，不写小作文、不解释。
- 创始人 Diogo Almeida：前 OpenAI 研究员，2022 年 InstructGPT 论文共同作者，沉寂约两年后发布此模型。

## 二、机制与口径（讲师理解用，不上屏）

- 输入：程序状态或文本情境 + 类型化问题；输出：判定 + 校准置信概率（calibrated confidence）。
- 三种问题类型（各源转述略有出入，以官方文档为准）：**Choice**（从给定选项中选择）、**Score**（按标准评分）、真伪/概率判断（有媒体写作 Noul，也有转述称 boolean，返回 0–1 数值）。Choice 和 Score 返回概率分布 + 置信度。
- 训练方法 **RLCD**：面向"校准决策"的强化学习——目标是让模型报出的概率真实反映实际对错，与 RLHF 优化人类偏好不同。
- 定位：**塞在 Agent 循环 / 软件流程里做高频小判断**（下一步走哪、停没停、分类、路由、达标没达标），不是拿来聊天或写文档的。
- 官方口径性能（**仅官方宣传，无独立验证**）：比前沿大模型快 20–200 倍（OSCHINA 转述为 40–200 倍）；成本最高降至 1/400；定价有"按次 $0.042"与"输出 token 免费"两种转述，上屏前以官网为准。

## 三、跟本课的关系（为什么放在 Agent 事故页之后讲）

- 本课 Agent 公式：**Agent = 模型 + 工具 + 循环 + 你给的停止条件**。循环每转一圈都在做小判断——这些判断以前是"让会说话的模型答一道题，再从它的话里抠答案"，慢、贵、还可能解析错。
- Jev 这类决策模型把判断变成**一个带把握的数**："初稿写完了吗？"→「完成，把握 0.62」。
- **回扣三课母题**：概率给了刹车一个刻度——把握低于多少就升级给人，这条线（阈值）必须你画。**先有刹车，再谈自主**，这一点没有变。

## 四、争议与风险（讲之前必读）

- 发布仅一周，宣传声量极大（"不说话的 AI 刷屏""2400 万人围观"），**独立/第三方评测尚未出现**，性能倍数均为官方口径。
- 已有质疑：拿专职决策模型与通用生成模型比赛判断类任务，对比的公平性存疑。
- 课堂纪律：**只讲"判断开始有专职模型"这一个方向性结论**，不上倍数、不上定价、不讲 RLCD；学员追问再从本文件取弹药。

## 五、备用弹药（学员追问时才给）

> 学员问"那我们的 Agent 是不是该换上它？"——答：它解决的是"判断这一步慢、贵、可能解析错"，不解决"判断错了谁负责"。你的停止条件、你的阈值、你的验收标准一样都不能少；工具换不换，等独立评测出来再定。
>
> 学员问"它会不会出错？"——答：会，所以才报"把握有多大"。把握 0.62 的意思是它自己承认快一半的可能不对——这正是要你把关的地方。
