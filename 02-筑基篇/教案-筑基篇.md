# 二、教育学原则 → 教案落点（核心）

| 原则 | 翻译成人话 | 对应教案落点 |
| --- | --- | --- |
| ① 成人学习原理（诺尔斯） | 用学员自己的岗位任务教，学了马上能用 | 开场就问"上节课的作业你做成了吗"；组块三练习写自己的真实任务；课后作业是本周真实任务 |

| ⑥ 主动建构 + 社会学习（建构主义） | 让人自己建构、同伴互相学 | 组块三给自己的真实任务选件，抽 2–3 人念、其他人用两问挑漏洞 |

**贯穿全场的"咯噔"结构**：先让学员表态（制造预期）→ 翻页/揭晓（打破预期）→ 一句机制解释（原来如此）。表态用举手，零成本、不占时间。**本课 4 个咯噔点：①"你以为在问问题，其实在下订单" ②RAG 是开卷考，翻错页它不会说 ③Skills ≠ 更长的提示词，是按需加载 ④Agent 最危险的不是做错，是自认为做完了。**

# 三、学情分析与教学目标

## 学情分析

- **学员背景**：企业内部员工，非技术岗为主。多数已听过或用过 AI，部分在第 1 课后尝试过。常见误区有两个极端：一是"AI 听不懂人话，得学咒语"，二是"提示词就是模板，背一个万能的就行"。
- **起点水平**：已完成第 1 课，掌握"能力边界三问"和"人必须复核"的中间态规则。**不需要编程基础**，练习纸笔即可参与。
- **学习动机**：第 1 课解决了"哪些能交"，但回去一用发现"交出去做出来的东西不能用"——本课直接接这个落差。
- **成人免疫提醒**：本课内容极易讲成"名词解释大会"。**每个名词必须绑一个"它解决什么问题"，否则学员只带走四个英文词。**

## 教学目标（三维）

- 知识与理解：能说出四件套各自解决什么问题、又留下什么新的坑（一句话一件）。
- 技能与应用：能用「两问选型法」（这个信息模型有没有？这件事要不要重复做？）判断一个任务该用提示词 / RAG / Skills 哪一件；能给 Agent 任务写出停止条件。
- 迁移与态度：能把"四要素"用到本周的一个真实任务上；对 Agent 从"好酷"转为"先想好刹车再放手"。

# 五、教学过程（40 分钟详案）

**时间合计 = 3 + 2 + 11 + 13 + 8 + 3 = 40 分钟。**
组块一 11′ = 2′讲（三种写法）+ 2′讲（四要素+研究）+ 4′练 + 3′评；
组块二 13′ = 2′讲 RAG + 2′数据页 + 3′讲 Skills + 4′练 + 2′评；
组块三 8′ = 1.5′讲 Agent 机制 + 1.5′失控数据 + 3′练 + 1.5′分享 + 0.5′对照。
请严格盯计时器（课件练习页自带倒计时）。**每次提问/练习后，必须先展示参考答案或示例（正误对比），讲评完才能进入下一环节。**

**提问节奏守则（全程适用）**：① 题目随计时同时亮出，全班并行思考/写——提问只"收"不"等"；② 冷叫三步：先问全班 → 给够思考时间（已含在计时内）→ 最后才点名，绝不先点名再出题；③ 无退出 + 兜底：答不出给一次提示或请旁人补一句，冷场 5 秒教师自答（"我先给个最常见的答案"），20 秒内必须接住；④ 一次提问只点 1–3 人、每人 20–30 秒，提问时间从"评"的预算里出。

**评价环节形式（讲师已定）**：一律用**抽 1–3 人公开讲评**（全班一起挑漏洞 + 讲师收口），**不用两人互评**——两人互评容易聊偏、讲师看不到全场、时间收不回来。

| 环节 | 时间 | 教师活动 | 学员活动 | 设计意图 / 对应原则 |
| --- | --- | --- | --- | --- |
| 破冰与痛点 | 3′ | 举手提问（1.5′）："上节课你列了'能交给 AI'的任务，回去真做了的请举手？做出来自认满意的请举手？"（第二次举手通常少一半，点 1–2 人说经历）。**举手后才翻页揭晓**："同样的任务、同样的模型，有人拿到能用的结果，有人拿到一堆正确的废话——**差别不在模型，在你给它的方式**。" | 两次举手，1–2 人口头说经历 | ① 成人学习：接第 1 课的真实落差；先表态后揭晓，注意力拉满 |
| 本课地图 | 2′ | 亮四件套阶梯图，**逐行点出"解决 → 留下"**：提示词（解决"它不知道我要什么"，留下"它不知道你的资料"）→ RAG → Skills → Agent。**强调"留下"就是下一件的来由**。只讲分工，一个名词都不展开 | 看懂四件套是一条台阶，不是四个名词 | ⑤ 组块化：先给全景；用"因果链"替代"名词表"，降低记忆负荷 |
| 组块一：讲（4′） | 11′ | **页 5（2′）**：现场演示同一任务三种写法 A／B／C，逐栏点出，**标题即结论："你以为在问问题，其实在下订单"**——没说清楚验收标准，它就按自己的理解交货。**页 6（2′）**：给「四要素」支架（角色 / 材料 / 格式 / 边界），右栏上研究数据：把任务说清楚提升最大、再补示例小幅提升、**堆形容词和角色扮演约等于没用**（素材：提示词效果研究，arXiv 2512.03818）。点破："不要自己补"这一句，比前面 50 个字都有用 | 先看三种结果差异，再记四要素 | ② 先看结果落差再给方法；③ 支架；右栏数据把"经验之谈"升级成"有实证背书" |
| 组块一：练（4′）+ 评（3′） | （含上） | 布置练习（题目随计时亮出）："给客户写一封催款邮件，款项已逾期 30 天——用四要素写一版提示词"。巡回看谁缺了"边界"。计时响后冷叫 2–3 人念自己的一版（卡住给提示，冷场 5 秒自答）；**随后展示教师版参考答案做正误对比**，重点讲"它会自己编金额和日期"这一条，讲评完再进组块二 | 独立写一版提示词，被提问者口头念，对照教师版自评 | ④ 当场纠偏；正误对比是学员获得感最强的时刻 |
| 组块二：讲 RAG（2′） | 13′ | **翻页前先问**："上节课说过模型有一个边界叫'不知最新'——那我把公司最新的产品手册传给它，它就知道了？"学员表态后揭晓：会，但**它不是学会了，是开卷考**——你的资料被切成一片片，它每次只翻相关的几片来抄；**翻到哪片就信哪片，翻错了它不会说"我没找到"**。一句话收口："RAG 解决'它没读过你的文档'，留下'同样的要求每次都要重说'。" | 先表态，再记"开卷考"这个心智模型 | ② 先判断再听讲；⑤ 一页一信息 |
| 组块二：数据页（2′） | （含上） | 亮斯坦福 RegLab + HAI 对两家法律 AI 工具的审计：号称"靠 RAG 做到无幻觉"的产品，实测**幻觉率 17%–34%**；另一项含 18 位医学专家的研究中，RAG 召回的片段里**只有约 22% 真正相关**。点破：**挂了知识库不等于更可靠，检索质量不达标时是负收益** | 预期被打破（以为 RAG = 无幻觉） | 咯噔点②；数据纠偏，防止学员把 RAG 当成免检章 |
| 组块二：讲 Skills（3′） | （含上） | 接上："所以第二件是 Skills——把那套角色+材料+格式+边界存成一个文件，下次一句话调用。"给三层数字（官方来源，Anthropic Skills 文档）：**平时只挂名字（约 100 tokens 常驻）→ 触发了才读正文 → 附带文件不读就是零成本**（课件把"约 100 tokens"口语化为"约 100 字"，同量级，非技术岗无需区分；学员追问时再给 tokens 口径）。**咯噔点③：Skills 和"一坨超长提示词"的根本区别不是更强，是按需加载。**类比手机 App，但**必须讲断裂点**：App 打开后代码全进内存，Skills 的附带文件仍是用到才读 | 记下"按需加载"这一条 | ③ ⑤；断裂点防止学员带走错误心智模型（设计经验 3） |
| 组块二：练（4′）+ 评（2′） | （含上） | 布置三选一练习（题目随计时亮出）：①把公司报销制度喂给它、回答员工提问 ②每周同样格式的周报 ③一次性的创意文案——各该用哪件？巡回抓"凭感觉没用两问"的学员；计时响后冷叫 2–3 人（判断+理由），**再展示参考答案**：①RAG ②Skills ③提示词，并给出**两问选型法**（这个信息模型有没有？→ 没有就 RAG；这件事要不要重复做？→ 要就 Skills）。重点讲③为什么不用 Skill | 独立写下判断和理由，被提问者口头回答，对照答案自评 | ③ 支架用法示范（每题都能被两问直接推出）；④ 反馈 |
| 组块三：讲 Agent（3′） | 8′ | **页 14（1.5′）**：亮 Agent 公式图——**模型 + 工具 + 循环 + 你给的停止条件**，最后一项用琥珀色高亮。演示一句任务："调研竞品 A 的定价并出一份对比表"——它自己拆成若干步、自己查、自己写，做完回来汇报。**页 15（1.5′）**：亮真实事故——两个 Agent 互相请求跑了 **264 小时（11 天）**、烧掉 **$47,000**，而发现方式是账单告警不是它自己停。**咯噔点④：Agent 最危险的不是做错，是它自认为做完了。**金句："先有刹车，再谈自主。" | 记下"停止条件必须由人给" | ⑤ 组块化；用事故数据替代"要小心"的正确废话 |
| 组块三：练（3′）+ 分享（1.5′）+ 对照（0.5′） | （含上） | 布置练习（题目随计时亮出）："给自己一个真实任务选件——提示词 / RAG / Skills / Agent，选哪个、为什么？"（写在纸上）。计时响后冷叫 2–3 人念，**其他人用两问挑 1 处漏洞**；**优先挑"选了 Agent 却没说停止条件"的项**——这是最多人踩的坑。被挑出不扣分，挑的人加分。**分享后亮教师版示例页（见下注），每人对照修正 1 处** | 独立写选件与理由，被提问者念，其他人挑漏洞，对照示例改 1 处 | ① 成人学习 ⑥ 社会学习；挑漏洞环节自带咯噔；④ 对照闭环收口 |
| 总结与行动 | 3′ | 一句话回顾："提示词是运气法门，RAG 是藏经阁，Skills 是功法秘籍，Agent 是分身——**四件不是四个词，是一条往上走的台阶**。"给谈资金句：**"你以为你在问问题，其实你在下订单"**（配"先有刹车，再谈自主"）。**系列钩子**："知道用哪一件了——但你的工作是一整条流程，不是一个任务。第 3 课把整条流程接起来。"布置作业：挑一个本周真实任务，用四要素写一版提示词；发反馈卡 | 复述四件套，写下行动承诺，填反馈卡 | ① 迁移 ④ 形成性评价；谈资金句 = 社交货币 |

**注·组块一教师版参考答案**（催款邮件）：
> 你是我的助理。请给客户写一封催款邮件。
> **材料**：客户名称【＿】、合同编号【＿】、逾期金额【＿】、逾期天数 30 天、原定付款日【＿】。
> **格式**：200 字以内，含一句友好的开场、明确金额与付款期限、一个联系方式。语气专业但留余地。
> **边界**：只写上面给出的信息；任何缺失数据一律标【待补】，**不要自己编造金额、日期或条款**。
讲评要点：学员最常见的缺口是"边界"——没有边界那句，模型会自己编一个金额和日期，而且编得非常像真的。

**注·组块二参考答案**（每题都能被两问直接推出）：
① 报销制度问答 → **RAG**（信息在制度里，模型没有 → 给它知识库）
② 每周周报 → **Skills**（同样的要求每周重复 → 存成秘籍）
③ 一次性创意文案 → **提示词**（信息模型有、也不重复 → 说清楚就行）

**注·组块三教师版示例**（分享后亮，每人对照改 1 处）：
① 每周客户例会纪要 → **Skills**——两问：要求每周重复 → 存成秘籍；边界：只写记录里有的，没写的标【待补】。
② 竞品定价调研 → **Agent + 停止条件**——流程不固定 → 让它自己拆；停止条件三件套：只查官网 + 2 份报告、预算 ≤ $5、30 分钟没结论就停下汇报——"先有刹车，再谈自主"。

**注·组块三抽评要点**：学员最容易出的两类漏洞——(a) 选了 Agent 但说不出停止条件与验收标准；(b) 明明是重复任务却选了提示词（该用 Skills）。讲师巡回时优先抓这两类上台。

# 六、评价设计

- 过程性评价（形成性）：催款邮件提示词对照教师版自评、三选一练习的提问回答质量、真实任务选件的分享质量 —— 原则 ④
- 总结性评价：组块三的"真实任务选件 + 理由"（是否真实、是否用了两问）+ 课后在岗作业 —— 原则 ①
- **验收标准（对应原则④，写进教案便于课后自查）**：下课前，学员应能 (1) 说出四件套各自的一句话定位；(2) 对任意一个给定任务用两问选出正确的一件；(3) 给 Agent 任务时主动写出停止条件。
- 反馈工具：课后 1 条反馈卡（最有用的一点 + 最想改进的 1 点）

# 八、分层作业与拓展

- 基础层：向一位同事用大白话解释"为什么给 AI 提要求要说清楚边界"（可以讲催款邮件会自己编金额的例子）。
- 进阶层（在岗作业）：挑一个本周真实任务，用四要素写一版提示词，记录加上"边界"那句话前后输出有什么不同。
- 拓展层：读素材库原文（提示词效果研究 arXiv 2512.03818 / Anthropic Skills 官方文档）；用两问选型法把自己部门的高频任务全部过一遍。
