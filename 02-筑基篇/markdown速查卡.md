# markdown 速查卡

> 《AI 修炼 · 第 2 课 · 筑基篇》随课资料 · 组块一 · 提示词
>
> 一句记住：markdown 是一种**排版写法**。它只改样子，不改内容——看不懂符号，你没有少拿到任何东西。
>
> （你现在打开的这份文件，看到的正是 markdown 的原样。先别管那些符号，读字就行。）

## 一、看懂 AI 回你的符号

| 你看到的 | 它的意思 |
| --- | --- |
| `# 大标题` | 一节的开头 |
| `## 小标题` | 一节里的小节 |
| `**加粗**` | 这是重点 |
| `- 一条` | 一条一条的清单 |
| `1. 第一步` | 有先后顺序的步骤 |
| `\| 竖线 \|` | 一张表格 |
| `> 引用` | 提醒或强调 |

**最省事的看法：只看标题和加粗。** 这两处通常是它给出的结论，其余是铺陈。

**符号看着乱？**直接补一句：

> 用普通段落重讲一遍，不要用符号。

很多软件会自动把这些符号渲染成好看的排版；你在聊天框里看到 `#` 和 `**`，只是那里没渲染而已。

## 二、你的提示词也这么写

四个小节，两分钟写完，可以直接抄：

```text
## 角色：你是我的____助理
## 材料：把原始信息贴在这里（缺的留【＿】）
## 格式：要几条、多长、什么结构
## 边界：只写我给的；缺的一律标【待补】，不要自己编
```

- 四个小节都写到，比堆一百个字形容词管用；
- **符号写错不要紧**——它认的是这四个小节，不是符号本身；
- 缺数据就留在【＿】里别删：你要的是它把空白还给你，不是它替你猜。

## 三、三个最常见的坑

1. **只说"帮我写一份…"** → 缺材料、缺格式、缺边界，它会自己编金额、日期、条款；
2. **数据不全却不标【待补】** → 它会给你一个很像真的假数字，你还得回头逐处核对；
3. **以为要背语法** → 日常够用的就三个符号：`#`、`**`、`-`。这不是编程，是排版。
