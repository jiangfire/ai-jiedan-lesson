# 素材库（讲师自备 + AI 搜集，讲师审查）

这里是课程的背景资料库。资料有两个来源：**你自己放的** 和 **AI 联网搜集的**——后者必须经过你审查才会被采用。

## 来源一：你自己放（直接可用）

- 行业数据、研究报告（数字类内容最有价值——模型的知识会过时，你的不会）
- 内部案例、真实业务场景（模型编不出来的那些）
- 好文章、金句、类比（写进讲师提示或开场白）
- 名词解释、常见误区清单
- 链接清单（md 里列 URL 即可，生成时会尝试读取）

md / txt / pdf / docx 均可，一个主题一个文件，文件名写清楚主题。

## 来源二：AI 联网搜集（待你审查）

生成教案时如果素材不足，AI 会自动联网搜索背景资料（真实案例、行业数据、研究结论），整理成 md 文件存进本目录。这类文件：

- 文件头标注 **来源 URL、检索日期、状态：待审查**；
- 生成前 AI 会列出清单（文件名 + 一句话内容 + 来源），**你确认或剔除后才用于生成**；
- 你确认后把文件头的状态改为"已审查"，下次直接可用；
- 搜得不好？直接删文件，或告诉 AI 换个方向再搜；
- 搜索优先权威来源（官方报告、学术研究、主流媒体），每个素材文件必须带来源 URL 供你核查。

## 通用规则

- 这里的内容**优先于模型自身知识**——两者冲突时以素材为准；
- 与课题无关的素材不会被强行使用；
- 生成后在教案末尾"参考资料"一节会列出用到了哪些文件，方便你核对；
- 课后补充了新资料？直接丢进来，让 AI 按新素材重出一版即可。

```
素材库/
├── README.md                        ← 本文件
├── LLM幻觉案例集.md                  ← 你自己放的（直接可用）
├── 2025-企业AI采用率数据-待审查.md    ← AI 搜集的（等你审查）
└── images/                          ← 配图时放图片的子目录（可选）
```
