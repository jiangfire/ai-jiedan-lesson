# AI 修炼三课课程库

企业内训课程「AI 修炼三课」的完整交付库：**练气（认知）→ 筑基（方法）→ 结丹（落地）**，每课 40 分钟，面向企业非技术岗学员。三课共用母题「**把关的是你**」，每课结尾埋下节课的钩子。

## 目录结构

```
三课大纲-AI修炼系列.md      # 系列总纲：定位、节奏、交付状态、上课前必做
01-练气篇/                  # 第 1 课：AI 是什么、边界在哪（三问模板）
02-筑基篇/                  # 第 2 课：把活交给 AI 的四件套（提示词/RAG/Skills/Agent）
03-结丹篇/                  # 第 3 课：把真实流程接成 AI 工作流（四步法 + 工作流卡）
  ├─ 教案-*.md              # 讲师用教案（可自由编辑）
  ├─ 课件-*.html            # 学员用课件（单文件离线，双击即播）
  ├─ AI工作流卡-模板.html    # 结丹篇 A4 打印模板（浏览器打开 Ctrl+P）
  └─ 素材库/                # 背景资料（含来源 URL 与审查状态）
素材审查记录.md             # AI 初核结论 + 讲师终审记录
配图清单.md                 # 课件配图的位置、提示词与处理规范
```

## 上课前必做

1. **审查素材**：逐份核对 `素材库/` 中「状态：待审查」的文件（AI 初核结论见 `素材审查记录.md`），确认后把文件头改为「已审查」；
2. **试播课件**：每份课件双击完整翻一遍（翻页、fragment、练习倒计时、S 键讲师提示、`?print-pdf` 打印导出）；
3. **结丹篇打印**：按人数打印工作流卡；提前一节课让学员想好「一条自己每周/每月都做的真实流程」。

## 生成与维护

- 教案与课件由自研 [lesson-plan skill](https://github.com/jiangfire/lesson-plan) 生成：教案按模板填 Markdown，课件以固定放映壳（1280×720，Reveal.js 内联，离线可用）生成；
- 课件壳为只读资产，仅允许维护升级（如整壳拼接同步）；日常修改请改教案后重新生成课件；
- 配图仅嵌「值得的图」，base64 内嵌，规范见 `配图清单.md`。
